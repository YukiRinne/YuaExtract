## 3. 关键架构事实（新会话必须知道）

### 3.1 扩展集（沿用上一轮，未变）

「扩展集」= 一部作品的「名字 ↔ 哈希」知识档案（`rules.int`），用于**免跑游戏**地还原同名游戏的资源名。
`file_hash = BLAKE2s-256(UTF16LE(名字+盐))`、`domain_hash = SipHash-2-4(UTF16LE(目录+盐))`（**目录小写 + 结尾斜杠，
结果字节反转**），**盐每游戏不同** → 档案存**名字**，加载时用**档案内嵌的盐**重算哈希。

模式1 三步 = ① 从扩展集生成静态 Hash 表（`StaticHash_Output`）② 提取动态 XP3 资源（**这一步仍要启动游戏**）
③ 用静态 Hash 还原。**「免跑游戏」免的是"跑游戏采哈希"，不是"解包"。**

### 3.2 在线更新（本轮新增）

```text
<repo>/
  index.txt                      ← 索引；就是一份 manifest.txt（10 列 TSV）
  <会社>/<作品>/rules.int        ← 档案本体（与 <工具目录>\ExtensionLibrary\<会社>\<作品>\ 同构）
```

- **基址解析顺序**：环境变量 `YUAEXT_ENDPOINT` → `YuaExtract.ini` 的 `[online] base=` → 常量
  `kDefaultRepositoryBase`。**已指向真实仓库** https://github.com/YukiRinne/Yua-Extensions
  （扩展集仓库本体验证配套在 `E:\Harness&Agent Project\YuaToolkit插件\YuaExtract仓库\`：tools + index + CI，见其 README）。
- **`raw.githubusercontent.com` 在国内经常连不上或极慢** —— 所以"基址可配置"是**功能前提**，不是锦上添花。
- **信任根是索引，不是本机 exe**：sha256 把"下到的字节"钉死在索引那一条；内嵌 exe 摘要必须等于**索引里的**。
- **工具验不了"名字对不对"**：档案 L3 哈希层**默认不存**（§3.1），本地没有可对照的哈希。
  "名字 + 盐 → 哈希算得回去"那套自校验**只在生成时成立**。名字的最终把关是**还原率这个事实**。
  界面与文档都**不许声称**能验证名字 —— 本页签右栏专门有一节「名字对不对，本工具验不了」。
- 索引行的 会社/作品 **必须等于**档案内嵌 META 的（§14.4 第 9 条）：否则"安装槽位"会有两个名字来源，
  用户看到的与实际落盘的会不是同一条。

### 3.3 布局 / 可见性铁律（沿用上一轮，本轮又踩到）

改可见性或位置之后**必须整窗重绘**（`RDW_ERASE | RDW_ALLCHILDREN | RDW_UPDATENOW`），
否则**分组框内部会留下旧像素**。新增页签也要落进这套流程（`EraseBehindTabControls` → 布局 →
`ShowTabControls` → `RedrawAllControls`）。E-11/E-12 的像素断言盯着这件事。

**⚠️ 两个必须知道的口径**

1. **看结论只认「总计：通过 N」**，不要只看那句"结论：全部通过" —— 本轮起汇总**分开报**
   "产品断言 / 脚手架自检"，避免把自检数当成产品覆盖（上一轮独立验证者提过这条）。
2. **`-Scope all` 不覆盖 supplement / pressure**。汇总固定列 9 个 scope 结果文件，
   所以 `-Scope all` 会报「**文件不存在 3 个**」（`checks-supplement.json` / `checks-selftest-supplement.json` /
   `checks-pressure.json`）—— 这是结构性缺项，**不是覆盖回退**。要那两组得单独 `-Scope supplement` / `-Scope pressure`。

**独立验证抓到过的东西（本轮）**

- **产品侧 P-1（中，真缺陷）**：索引名与档案 META 名**从不交叉校验** → 产品按索引名弹「已新增 A/B」，
  磁盘却落到档案 META 的 C/D；**覆盖确认框**按索引名找到的条目与实际被替换的条目可以不是一个。
  修法：入口就要求两边相等（§14.4 第 9 条）。

  P-6（索引里的 `%2f` 存活到 URL、由**服务端**解码）**只有远端侧影响，记录不修**。
- **脚手架侧 S-1（它亲手复现的假绿）**：`E-19/online-http-base` 的关键词表里前两个词**在那条路径上永远不出现**，

## 5. 环境与踩坑（省时间用）

**构建**（**必须先杀进程**否则 `LNK1104`；**同一时刻只允许一个人跑 MSBuild**）：

```powershell
Get-Process YuaExtract -ErrorAction SilentlyContinue | Stop-Process -Force
& 'C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\MSBuild.exe' `
  'YuaExtract.sln' /p:Configuration=Release /p:Platform=x86 /m /v:minimal /nologo
```

| 坑 | 说明 |
|---|---|
| **别在 Git Bash 里直接调 MSBuild**（本轮新踩） | MSYS 会把 `/p:Configuration=Release` 当路径转成 `p:Configuration=Release` / `M:/` / `C:/Program Files/Git/nologo`，报 `MSB1008 只能指定一个项目`。**走 PowerShell 调**（照上面的配方），或设 `MSYS2_ARG_CONV_EXCL='*'` |
| `LNK1104` / 构建串行 | 同上；多人改同一解决方案先约"构建窗口" |
| **改源码 → 指纹变 → 必须重跑验收** | 本轮为此重编了 4 次（`492522BD` → `E06CF49D` → `FAEB6760` → `71BF4A17`） |
| **在线更新用例要 https，夹具装了机器级自签证书** | `lib/serve-fixtures.ps1` 会把自己的证书装进 **`LocalMachine\Root`**（WinHTTP 只认机器信任库）—— 需要管理员，`-UninstallCertificate` 可卸。**注意：这是机器级信任锚，作用域不只是 localhost**（私钥就在本机，理论上可给别的域名签） |
| 其余（`PrintWindow` 会阻塞、`GetDIBits` 行跨距、PS 5.1 要 UTF-8 BOM、临时产物别落仓库根、PowerShell 变量名大小写不敏感） | 见 [`../_verify/restore-harness/README.md`](../_verify/restore-harness/README.md) 与上一轮归档 §5 |
