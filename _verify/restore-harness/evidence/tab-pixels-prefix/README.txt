实测差异（同一像素引擎 lib\HarnessPixels.ps1 复算，与断言口径一致）
------------------------------------------------------------------
* 四路制作页抓图**两两互不相同**（缺陷现场）：
  - 基线 vs 首页→制作 = 12,762 px / **1.369%**（最小信号）
  - 基线 vs 扩展集→制作 = 98,745 px / 10.591%
  - 基线 vs 来回切换后 = 66,478 px / 7.130%
  - 首页→制作 vs 扩展集→制作 = 86,487 px / 9.276%
  - 首页→制作 vs 来回切换后 = 53,716 px / 5.761%
  - 扩展集→制作 vs 来回切换后 = 32,771 px / 3.515%
* 首页也不干净：启动时 vs 回首页 = 107,863 px / **11.569%**
* **同一状态连拍两张 = 0 px**（噪声地板 0.0000%；由另一次同进程连拍实测）
* 对照：这批图下**可见性口径全绿**（首页控件的 `IsWindowVisible` 全是 False）——
  这就是"可见性断言看不见幽灵"的实测证明。

阈值关系的结论：噪声地板 0.0000% ← **阈值 0.10%（制作页签）/ 1%（首页）** → 最小缺陷信号 1.369%。
详细标定与判据设计见 `..\..\README.md` 的「E-11」一节。

格式说明
--------
* 仓库里存的是 **PNG**（每张 ~60-80 KB；BMP 每张 2.8 MB）。
* 比对前由 `lib\HarnessPixels.ps1` 的 `Convert-PngToBmp`（Pillow，带 `.convert('RGB')`）
  无损转回 BMP：**往返逐像素自检 0 差异**，所以判据数值与当年 BMP 完全一致。
* 断言**只读**这些图，不启动产品、不读现场（README 踩坑 #22）。
